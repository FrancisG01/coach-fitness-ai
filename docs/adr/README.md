# Registro de decisiones (ADR)

Las decisiones D-01 a D-18 tomadas en la planificación están en docs/plan-maestro.md, sección 20.
El agente arquitecto las convierte en archivos individuales durante la Fase 0, usando los números 0001 a 0018 (reservados: el número del ADR coincide con el de la decisión).

Desde la D-19, cada decisión nueva se registra directamente como ADR con su mismo número y se agrega una fila a la sección 20 del plan.

Formato de cada ADR: contexto, decisión, alternativas consideradas, consecuencias, fecha.
